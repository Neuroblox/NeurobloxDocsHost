Build graphs using the @graph macro

@graph begin
    @nodes begin
        (...)
    end

    @connections begin
        (...)
    end
end

or

@graph name begin
    @nodes begin
        (...)
    end

    @connections begin
        (...)
    end
end

Build a GraphSystem from a list of nodes corresponding to blox and a set of connections between the nodes.

Nodes are defined using normal Julia assignment syntax, and connections are defined using pair syntax, followed by an optional tuple of keyword arguments for the connection.

@graph begin
    @nodes begin
        nn1 = HHExciNeuron(name=Symbol("nrn1"), I_bg=3)
        nn2 = HHExciNeuron(name=Symbol("nrn2"), I_bg=2)
        nn3 = HHInhiNeuron(name=Symbol("nrn3"), I_bg=2)
    end

    @connections begin
        nn1 => nn2, (weight = 1)
        nn2 => nn3, (weight = 1)
        nn3 => nn1, (weight = 0.2)
    end
end

The name kwarg of the nodes will be set equal to the variable they're assigned to, and their namespace equal to the name of the outer graph (default nothing).

Node metadata

Arbitrary metadata can be attached to a node by appending a tuple of keyword arguments after the constructor call:

@graph begin
    @nodes begin
        nn1 = HHExciNeuron(I_bg=3), (position = (1, 2))
        nn2 = HHExciNeuron(I_bg=2), (position = (3, 4), layer = 2)
    end
end

The metadata tuple is passed to the blox constructor as metadata = pairs((; kwargs...)). All of the following forms are accepted:

# Single kwarg — no trailing comma needed
nn = SomeBlox(), (position = (1, 2))

# Multiple kwargs — comma-separated inside parens
nn = SomeBlox(), (position = (1, 2), layer = 2)

# Trailing-comma tuple (explicit 1-element tuple)
nn = SomeBlox(), (position = (1, 2),)

# Named-tuple form with semicolon
nn = SomeBlox(), (; position = (1, 2), layer = 2)

Connection syntax

The @connections block supports several forms:

@connections begin
    # DefaultRule with kwargs passed to the constructor
    a => b, (weight = 1.0)
    a => b, weight = 1.0       # single-kwarg shorthand

    # Explicit connection object (no extra kwargs)
    a => b, MyRule(1.0)

    # Explicit connection object + metadata kwargs stored on the edge
    a => b, MyRule(1.0), (color = :red, width = 2.0)

    # No spec → DefaultRule()
    a => b
end

When the three-element form src => dst, conn, (kwargs...) is used, the kwargs are forwarded to add_connection! and stored in connection.metadata.

Graph metadata

Graph-level metadata can be attached using a @graph_metadata block. Each entry is a key => value pair, where the key is a Symbol and the value is any Julia expression. The pairs are stored in the metadata::OrderedDict{Symbol, Any} field of the resulting GraphSystem.

g = @graph begin
    @nodes begin
        ping_exci1 = PINGExciNeuron()
        ping_inhi = PINGInhiNeuron()
    end

    @graph_metadata begin
        :solver_settings => Dict(:solver => :stiff)
        :datafiles => ["image_example.csv"]

        # Normal Julia code is allowed inside the block
        x = 5
        :x_squared => x^2
    end
end

g.metadata[:solver_settings]  # Dict(:solver => :stiff)
g.metadata[:x_squared]        # 25

One can insert normal Julia code outside of the @nodes and @connections blox to improve readability or perform other logic:

@graph begin
    μ_E = 1.5
    σ_E = 0.15
    μ_I = 0.8
    σ_I = 0.08

    @nodes begin
        ping_exci1 = PINGExciNeuron(I_ext = rand(rng, Normal(μ_E, σ_E)))
        ping_exci2 = PINGExciNeuron(I_ext = rand(rng, Normal(μ_E, σ_E)))
        ping_inhi = PINGInhiNeuron(I_ext = rand(rng, Normal(μ_I, σ_I)))
    end
end

Defining nodes and connections in loops

Nodes and connections can also be defined programmatically using for loops and comprehensions. The syntax here is rigid:

The syntax for nodes is rigid: nodes must have an assignment still. For example, writing:

@nodes begin
    exci_neurons = [HHExciNeuron() for i in 1:10]

    inhi_neurons = for i in 1:10
        HHInhiNeuron()
    end
end

will assign the array of 10 excitatory neurons to exci_neurons and the array of 10 inhibitory neurons to inhi_neurons. (Note that this is different from how normal for loops behave.)

By default, the neurons inside will have the name of the array, followed by their index. For example, the first excitatory neuron will have the name exci_neurons_1.

Assignments are allowed inside for loops. For example, we can write

@nodes begin
    exci_neurons = [HHExciNeuron() for i in 1:10]

    inhi_neurons = for i in 1:10
        name = "my_neuron$i"
        HHInhiNeuron(name = name)
    end
end

to manually pick the names assigned to the inhibitory neurons. However, the last line of the for loop must be a blox constructor call.

Edges and for loops can be defined using a comprehension as well.

@graph begin
    @nodes begin
        if_neurons = [IFNeuron(I_in = rand()) for _ in 1:2]
        qif_neuron = QIFNeuron(I_in = rand())
    end

    neurons = [if_neurons; qif_neuron]

    @connections begin
        for (n1, n2) in zip(neurons, neurons)
            n1 => n2, (weight = 1)
        end
    end
end
